# 2028 US State Elections

Open `report/index.html` in a browser for the initial report. Open `report/overview.csv` and `report/contests.csv` in Excel or import them into Google Sheets. The HTML filter works offline. The CSVs are snapshots regenerated by the tool.

## Turn on weekly updates

1. Unzip this package and push its contents, including the hidden `.github` directory, to the default branch of a GitHub repository you control.
2. Enable GitHub Actions for the repository. The workflow uses the repository token to commit updates, so the default branch must allow workflow commits.
3. Under **Actions → Refresh election report**, choose **Run workflow**. Check that the run succeeds and updates the files under `report/`. The run also provides an **election-report** download containing the HTML and both CSVs.

The workflow is scheduled for Mondays at 14:23 UTC. GitHub can delay scheduled runs and can disable them in inactive public repositories. The owner can change the cron expression or disable the workflow after the 2028 cycle. To share access, grant the recipient access to the repository or send the downloaded report. Repository visibility is your choice.

## Refresh locally

With Python 3.10 or newer, install dependencies using `python -m pip install -r requirements.txt`, then run `python refresh.py` from the extracted directory. Reopen the HTML or CSVs after each run.

## Coverage and sources

The report covers the 50 U.S. states. Ballotpedia provides the public indexes behind the governor, legislature, executive, state supreme court and statewide ballot measure summaries. Individual rows cover governor races, supreme court elections, listed executive candidates and qualified ballot measures. Follow the Legislature source for district-level coverage and state election officials for official calendars and certified results. Candidate status reflects the source, and a declaration does not establish ballot qualification.

Each category shows its last successful refresh. If a source fails or an expected page structure changes, last successful data for that category remains available and the workflow flags the failure. Check the failed run’s log before changing the parser.
